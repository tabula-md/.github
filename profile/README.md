## Open-source components

| Repository | Role |
| --- | --- |
| [`tabula-md`](https://github.com/tabula-md/tabula-md) | Local-first Markdown workspace and browser app. |
| [`tabula-mcp`](https://github.com/tabula-md/tabula-mcp) | Connects Codex, Claude, and other MCP clients to shared workspaces. |
| [`tabula-room`](https://github.com/tabula-md/tabula-room) | Encrypted realtime relay for live sessions. |
| [`tabula-json`](https://github.com/tabula-md/tabula-json) | Encrypted snapshot storage for Export links. |

For bugs and feature proposals, use the affected repository's Issues. Report
security vulnerabilities privately using that repository's `SECURITY.md`.
